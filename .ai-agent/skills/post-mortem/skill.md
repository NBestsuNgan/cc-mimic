# Post-Mortem Skill

## Instructions
When this skill is invoked, perform a post-mortem analysis:

1. Identify what happened
2. Identify the root cause
3. Suggest preventive measures
4. Document the timeline

## Output Format
Provide a structured post-mortem with:
- Summary
- Root Cause
- Impact
- Remediation
- Prevention Steps
