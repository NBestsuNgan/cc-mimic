# ⌁ cc-mimic

A lightweight Claude Code mimic — forge your own AI coding agent.

---

## ⚡ Quick Start

### Prerequisites

```bash
# Create a virtual environment
python3 -m venv .venv
source .venv/bin/activate
```

### 📦 Installation

```bash
cd ~/Users/user_name/desktop/cc-mimic
pip3 install -e .
```
